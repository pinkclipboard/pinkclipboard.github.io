How to use Clinically Unhinged

🎮 Study game

Select one of 15 systems, choose Pathophysiology, Pharmacology, Most Common Diagnoses, or Assessments, then complete a short round. Diagnosis rounds separate diagnosis, testing, and treatment decisions.

📚 Clinical library

Use the reference cards to review disease mechanisms, medication classes, clinical presentations, examination sequences, and lifespan adaptations.

🏆 Progress

Scores and completed questions are stored using this browser's local storage. Export a JSON backup if you want to move your record to another device.

🧬 Lifespan thinking

Consider pediatric, pregnancy, breastfeeding, and geriatric implications. The selected lens is a prompt to think critically—not a substitute for individual assessment.

Important educational limitation: This is a study aid, not a clinical decision-support system. Content is a curated starting framework, not an exhaustive board review or a substitute for current guidelines, drug labeling, local protocols, or clinician judgment. Verify medication dosing, pregnancy/lactation safety, contraindications, and diagnostic pathways using authoritative current references before clinical use. Some questions are simplified for learning.

Access anytime

This is a standalone website file. Save it on your device and open it in a modern browser. Progress persists in that browser on that device; use Export progress for a backup. To access it through a permanent shareable URL on multiple devices, upload the file to a static hosting provider such as GitHub Pages or Netlify.
